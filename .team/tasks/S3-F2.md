## 2. Privacy-policy page: new `pages/privacy/index`
Plain reading page, both locales, sections:
1. Who operates the service (`operatorName`, `contact`).
2. What we store about staff: name, title, department, role, the WeChat openid binding created when an invite code is redeemed; schedule items, notes and vehicle requests they create or are part of.
3. What staff enter about visitors: name, organisation, plate number; the plate is cleared `plateRetentionDays` days after the visit.
4. Why: internal scheduling, meeting rooms, vehicles and visitor reception for the company only. No advertising, no sale, no sharing outside the company except the hosting provider (Tencent CloudBase).
5. Where and how long: Tencent CloudBase in mainland China; operation logs kept `auditRetentionDays` days; data of a disabled employee kept until an administrator deletes it.
6. Your choices: ask the administrator to correct or delete your data; contact line.
7. Policy version and effective date (the version from config; the date as a locale key you leave as a placeholder for the owner).
Keep the wording plain and short. Put the copy in locale keys (`privacy.*`). Add a Glossary row only if you introduce a new term.

## 3. Consent flow
- **New `utils/privacy.js`:** `accepted()` → true when local storage holds `{ version }` ≥ `config.PRIVACY.version`; `accept()` stores it; `needsConsent()`. Wrap storage in try/catch; a failed read means "not accepted". Add Node tests (`tests/privacy.test.js`) with a fake `wx` storage.
- **Bind page (remote mode):** below the code input, a checkbox line "我已阅读并同意《隐私政策》" / "I have read and agree to the Privacy Policy", where the policy title links to `pages/privacy`. The submit button stays disabled until it is checked; on a successful redeem call `accept()`.
- **Already-bound users (remote mode) and the demo:** if `needsConsent()` after `auth.ready()` resolves `bound`, show a blocking sheet on the home tab (title, one-sentence summary, "查看隐私政策" link, buttons 同意 / 不同意). 同意 → `accept()`. 不同意 → `wx.exitMiniProgram()` (wrapped in try/catch; on failure keep the sheet). Do this once in a shared place (for example `utils/shell.js` `prepareTab`), not per page.
- **WeChat privacy authorization:** in `app.js`, register `wx.onNeedPrivacyAuthorization` (guarded: only if the function exists) so that if any privacy-sensitive WeChat API is ever triggered, the same sheet is shown and the `resolve` callback receives `{ buttonId, event: 'agree' }` from a `<button open-type="agreePrivacyAuthorization" id=…>` or `{ event: 'disagree' }`. List in your reply which WeChat APIs the app calls today that fall under the privacy guide (for example clipboard); do not add new ones.
- **Me:** add a "隐私政策 / Privacy policy" row that opens the page.
