# S1-F2-r1: review fixes for S1-F2 (owner: cursor-exec)

The lead review approves the components overall. Fix these:

1. **Required: do not name custom component events `tap`.**
   - The native `tap` event from inner elements bubbles out of a custom component.
   - A page writing `<primary-button bindtap="onPrimary">` therefore receives the native tap, even when the button is disabled or loading, plus your custom `tap`. That is two calls, and the disabled guard is bypassed.
   - Rename the custom event to **`press`** in `primary-button` and `cell-row`, and update the dev gallery to `bind:press`.
   - Inside each component, catch the internal tap with `catchtap` so the native event does not leak out.
   - Do the same review for `bottom-sheet` (`close`/`confirm`), `state-view` (`action`/`secondary`) and `notice-bar` (`close`). Use `catchtap` internally so a tap inside the panel cannot reach page handlers.
2. In `bottom-sheet`, make sure a tap on the panel itself does not close the sheet. Only the mask and cancel do. `catchtap` on `.panel` with a no-op is fine.
3. Run `npm test`, `npm run check` and `node --check` on the changed JS. Keep the verification to those commands. You don't need to measure text widths again for this change.
