## Rule: components are copy-free
- Components never call `i18n` and contain no literal copy. Every visible string arrives through a property, already translated by the page with `this.t()`.
- That keeps them reusable and keeps the CJK lint and i18n contract simple.
- One exception: `aria-label` / `aria-role` values also come in as properties.

## Components (`miniprogram/components/<name>/index.{js,json,wxml,wxss}`)
Use `Component()` with `options: { addGlobalClass: true }` so they can use the `app.wxss` utilities.

1. **`state-view`**
   - Properties: `kind`: `empty | error | loading | success`; `title`; `body`; `actionText`; `secondaryText`.
   - Events: `action`, `secondary`.
   - Layout: a round icon badge (empty: neutral; error: danger tone; success: ok tone), a title and one line of body text. Show an optional primary action and an optional secondary text action (for example "reset" under an error).
   - `loading` shows 3 skeleton rows (short grey bars) instead of an icon, per DESIGN 状态 加载.
2. **`status-pill`**
   - Properties: `text`, `tone`: `warn | info | ok | danger | mute`.
   - Uses the `.pill` classes.
   - Also export a plain helper `miniprogram/utils/status-tone.js` that maps:
     - meeting statuses: upcoming→warn, ongoing→info, done→mute, cancelled→mute
     - vehicle statuses: pending→warn, assigned→info, done→ok, rejected→danger, withdrawn→mute
   - Unknown statuses → mute, plus a `console.warn`.
3. **`cell-row`**
   - Properties: `label`, `value`, `stacked` (bool), `arrow` (bool), `required-error` (bool, which draws the danger state for P1-7 inline errors), `errorText`.
   - A `<slot>` replaces `value` when the form needs a picker or input.
   - Event: `tap` (only when `arrow`).
   - Minimum height 48px. When the label is longer than about 45%, it must wrap, never overflow. Check with an English label like "Departure date".
4. **`bottom-sheet`**
   - Properties: `show`, `title`, `cancelText`, `confirmText`, `confirmDisabled`, `danger` (bool, a red confirm for destructive actions).
   - Events: `close`, `confirm`.
   - Has a `<slot>` for content.
   - Behavior:
     - The mask closes it.
     - `catchtouchmove` on the mask prevents scroll-through.
     - It respects the bottom safe area.
     - Slide-up animation of about 200ms, done with CSS transitions only.
   - Radius 16 on top (DESIGN).
5. **`primary-button`**
   - Properties: `text`, `disabled`, `loading`, `loadingText`, `reason`.
   - Event: `tap`, which does not fire when disabled or loading.
   - `reason` is the 12px line under a disabled button that explains why (DESIGN 主按钮).
   - Fixed to the bottom on sub-pages through `fixed` (bool) with a safe-area pad; otherwise inline.
6. **`notice-bar`**
   - Properties: `kind`: `success | error | info`; `text`; `closable`.
   - Event: `close`.
   - The success and error bars from DESIGN (light green / light red, radius 8).
   - Rule from review P2: a **banner** when the user lands on a new page after an action; a **toast** (`wx.showToast`, used by pages, not here) when they stay.
7. **`top-progress`**
   - Property: `active`.
   - A 2px indeterminate bar under the nav for loading and submitting (DESIGN 状态 加载).

## Touch targets (review P2)
Any tappable element (sheet buttons, cell rows with an arrow, the notice close button, the state actions) has a hit area of at least 44×44px. Use padding or a pseudo-element if the visual size is smaller.
