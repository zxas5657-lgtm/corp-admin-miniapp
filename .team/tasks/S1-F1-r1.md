# S1-F1-r1: review fixes for S1-F1 (owner: cursor-exec)

Lead review of F1: the tokens, utility classes, custom tab bar, icons, project config and app.json are approved. Fix the items below. Keep the change small.

1. **Required: build pages with `Component()`, not `Page()`.**
   - `behaviors/i18n.js` relies on `lifetimes.attached/detached`, `pageLifetimes.show/hide` and `definitionFilter`. A `Page()` constructor with `behaviors` only merges `data` and `methods`; those lifetimes and `definitionFilter` are not reliably invoked. That means titles and tab texts would never refresh.
   - Convert all four pages to `Component({ behaviors: [i18nBehavior], data: {...}, methods: { onLoad() {}, onShow() {} } })`. WeChat supports Component-constructed pages, with page events in `methods`.
   - Keep the behavior's `pageLifetimes` approach.
2. **Remove duplication.**
   - Each page declares `i18nKeys`, `navTitleKey` and `tabIndex` **once**, in `data`.
   - Drop the top-level option copies and the `definitionFilter` (no longer needed).
   - Drop the per-page `onShow` that calls `setSelected`; the behavior already does it from `tabIndex`.
   - Each page file should end up about 10 lines.
3. **Remove the defensive `try { require('../i18n/index') } catch` wrappers.** B2 has landed.
   - Require i18n directly in `behaviors/i18n.js`, `custom-tab-bar/index.js` and `app.js`.
   - Remove the `typeof i18n.x === 'function'` guards and the `|| 'zh-CN'` fallbacks for API functions that are part of the contract.
   - Keep the try/catch around `wx.*` calls only.
4. **Initial locale on the tab bar.**
   - After the conversion, check that the tab bar shows the right texts on first paint. `attached` + `setTexts(dict('tab'))` should cover it.
   - Make sure a locale change while on any tab updates both the bar and the visible title.
