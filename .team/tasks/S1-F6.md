  - Locale: `store.getLocale()` if set; otherwise the system language (the existing code). Then `i18n.setLocale(...)`.
  - Replace the TODO.
- **Language change rule.** The Me page calls **both** `i18n.setLocale(x)` and `store.setLocale(x)`; `store.setLocale` only persists.
  - Put that pair in one helper, `miniprogram/utils/locale.js` `changeLocale(x)`, which returns the store result. This is the only place a locale change happens.

## 2. Me page (`pages/me/index`)
Build it as a `Component()` page with the i18n behavior. Use the F2 components (with the r1 event names: `bind:press`, etc.).
- **Header:** an avatar circle with the initial (zh: first character of the zh name; en: first letter of the en name), the person's name (`localName`), their title, and their role label. The person comes from `ROLES[store.getRole()]`.
- **Language row:**
  - label `me.language` (it reads `语言 / Language` in both locales)
  - value is the current language name (`lang.zh` / `lang.en`)
  - tapping opens a `bottom-sheet` with two options, `简体中文` and `English`, plus a check mark on the current one
  - choosing one calls `changeLocale` and closes the sheet; the page re-renders through the behavior with no restart
  - on a storage failure, show an error `notice-bar` with `error.storage.writeFailed`, and keep the in-memory locale switched
- **Entry card (P1-2):** a visible card with two large rows, 来访接待 / Visitor reception and 行政日常 / Daily admin, each with a short sub-line. They navigate to the skeleton pages.
- **Demo section**, only when `DEV_ROLE_SWITCH`:
  - The section title and hint are under `demo.*`.
  - Four radio rows in `ROLE_ORDER`: role label, person name, role hint.
  - Selecting a role calls `store.setRole`, shows a toast (staying on the page means a toast, per P2), then `wx.switchTab` to the role's home: driver goes to `/pages/vehicles/index`, everyone else to `/pages/schedule/index` (P1-2).
- **Reset demo data:** a row that opens a `bottom-sheet` with `danger` confirm.
  - Body copy says the demo data will be restored and the **language setting is kept**.
  - Confirm calls `store.resetDemo()`, then shows a toast on success or an error notice on failure.
  - This row sits in the demo section too, behind the same flag.
