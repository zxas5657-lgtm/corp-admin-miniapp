## P1. Most pages have no side gutter: content is flush with the screen edge
Every page except schedule (shots 04–29: cards, titles, links, buttons at x≈0–3; coloured slivers at x=0).
Cause: the `.page` rule's `padding` shorthand contains `calc(... + constant(safe-area-inset-bottom))`. Current WebViews treat `constant()` as invalid, so the **whole shorthand is dropped**, side padding included; only the following `padding-bottom: env(...)` line survives.
- Fix in: meetings, meeting-detail, meeting-form, vehicles, vehicle-detail, vehicle-form, me, visitors, daily `index.wxss`. Write the plain shorthand without safe-area (`padding: 16px 16px 24px` style, using the existing vars with fallbacks), then the `padding-bottom: calc(X + constant(...))` and `padding-bottom: calc(X + env(...))` pair after it.
- Grep the whole `miniprogram/` for any other shorthand (`padding`, `margin`, `inset`) that mixes `constant(` in; single-property lines followed by an `env()` line are fine.
- After the fix, check that the meetings filter chips ("All" was clipped at the left), the fixed bottom buttons, and the vehicle-form "Submit request" button (flush to edges, 23) have proper gutters.
