## The page is a thin binding
`pages/schedule/index` is a `Component()` page with the i18n behavior.
- **Recompute** `view = scheduleView({ state: store.getState(), date: store.ui.getSelectedDate(), now: clock.now(), focusId })` and `setData({ view })`. This happens:
  - on `show`
  - on locale change (hook into the behavior: add an overridable `onLocaleChange` method that `applyI18n` calls if present, or recompute in your own `onChange` subscription)
  - on `store.subscribe`
  - on date change
  - on a **60s timer** while the page is visible, so meeting status moves upcoming → ongoing → done (review P0-3). Clear the timer on hide and on detach.
- **Do not compute** statuses, labels, dates or empty states in the page. If the view model lacks something you need, list it in your reply instead of computing it.

## Layout (match the prototype's schedule screen)
- **Day heading row:** `view.dayHeading`, `view.countText` (small, right), and a `view.backToToday` text button when it is not null.
- **Week strip:** the 7 `view.week.days` in a fixed row, with prev/next week chevrons on each side (`view.week.prevDate` / `nextDate`).
  - Each day shows the weekday label above the day number. Selected is a primary filled circle; today is the primary-colored number when not selected; a dot below means `hasItems`.
  - Tapping a day sets the selected date. Every tap target is at least 44px. The strip does **not** re-centre.
  - Add a date-picker shortcut (`<picker mode="date">`) behind a small calendar icon at the end of the heading row. Its aria-label comes from `a11y.weekPicker`.
- **Item cards:** use the `.card` class, with a 3px left bar (meeting blue, vehicle amber via `.card.vehicle`).
  - Line 1: `timeText` (tabular numerals) and the `status-pill` on the right.
  - Line 2: `title` (16/600, two-line clamp).
  - Line 3: `subtitle` (13px secondary).
  - **Meeting cards** navigate to `item.url` with `wx.navigateTo`. The meeting-detail page arrives in F4; until then a navigate failure must not crash the page (catch `fail`).
  - **Vehicle cards are not tappable yet**, so show no chevron. Vehicle detail is Sprint 2.
- **Focus (review P1-6):**
  - On `show`, call `store.ui.takePendingFocus()` **once**. If it returns `{ date, meetingId }`, set the selected date, pass `focusId`, scroll to that card (`wx.pageScrollTo` with selector `#item-<id>`), and play a 1.2s highlight (a soft primary-tinted background fade done with CSS animation).
  - Do not persist the focus anywhere. A later `show` has no focus.
- **Success banner:** if the pending focus also carries `banner: true`, show `notice-bar` success with `t('meeting.created')` and the date param from `fmt.dayHeading`, auto-hiding after 4s. F5 sets this banner when it navigates here.
- **Empty state:** `state-view` with kind `empty`, `view.empty.title` and `view.empty.body`. No action button.
- **Load error:** if `getApp().globalData.loadResult.ok === false`, show `state-view` kind `error` with `state.genericErrorTitle` / `state.genericErrorBody`, a retry action (`store.load()` again), and a secondary reset action (`store.resetDemo()`).
- The page bottom is padded for the custom tab bar and the safe area.

## English and narrow screens
- Verify the heading row with `"Sat, Oct 24"`, `"3 items"` and `"Back to today"` at 320px. When space is short, the heading row wraps `backToToday` under the date; never truncate the date.
- Card titles clamp to two lines; subtitles take one line with ellipsis.
