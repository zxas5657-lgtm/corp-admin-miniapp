# S1-B3: clock, dates, reference data, seed (owner: codex-exec)

Context: PLAN.md §1.3. CLAUDE_REVIEW.md P0-2, P0-3 and §5.2 rules 4–6. DESIGN.md: 原型数据 and the new 小程序字段 list.
CommonJS, no deps, no `wx`, no DOM. The CJK-literal lint covers `domain/`. `data/` may contain Chinese, since it is seed and reference data.

## Files

1. **`miniprogram/domain/clock.js`**
   - `DEMO_NOW = '2026-10-24T09:20'`, a local wall-clock time.
   - `now()` returns a `Date`. In demo mode (the v1 default) it returns the demo instant; otherwise it returns `new Date()`.
   - `setDemoMode(bool)`, `isDemoMode()`, and `setNow(dateOrNull)` (a test override).
   - Domain functions never call `clock.now()` themselves; they take `now` as a parameter. Only pages and the store call the clock.
2. **`miniprogram/domain/dates.js`**: all local time, never a UTC parse of a `'YYYY-MM-DD'` string.
   - `isDateStr(s)`: a real calendar date; `'2026-02-30'` → false.
   - `isTimeStr(s)`: `HH:mm`, 00:00–23:59.
   - `toDateStr(date)` and `toTimeStr(date)` read a `Date`.
   - `nowParts(date)` returns `{ date, time }`.
   - `addDays(dateStr, n)`: crosses month and year boundaries.
   - `compareDate(a, b)` returns -1, 0 or 1.
   - `toMinutes('HH:mm')` returns a number.
   - `weekdayOf(dateStr)` returns 0–6.
   - `weekStart(dateStr, firstDay)` and `weekDays(dateStr, firstDay)` give the 7 date strings of the week containing `dateStr`. `firstDay` is 0 (Sunday) or 1 (Monday).
   - `isSameDay(a, b)`.
3. **`miniprogram/data/reference.js`**: ids plus `{ 'zh-CN': …, en: … }` names. Use those exact locale keys, which `i18n.localName` reads.
   - **ROOMS**: `f3-small` 3楼小会议室 / 3F Small Meeting Room; `f5-board` 5楼董事会会议室 / 5F Boardroom; `f1-reception` 1楼接待室 / 1F Reception Room; `online` 线上会议 / Online meeting, with `online: true`.
   - **PEOPLE**: id, name, title.
     - `p-chen` 陈启明 Chen Qiming, 总经理 General Manager
     - `p-lin` 林晓雯 Lin Xiaowen, 总裁办公室 President's Office
     - `p-zhao` 赵磊 Zhao Lei, 车队 Fleet
     - `p-zhou` 周宁 Zhou Ning, 前台 Front Desk
     - `p-sun` 孙倩 Sun Qian, 财务部 Finance
     - `p-ma` 马凯 Ma Kai, 综合部 General Affairs
   - **ROLES**: `{ leader: 'p-chen', admin: 'p-lin', driver: 'p-zhao', reception: 'p-zhou' }`, mapping each role to its default demo person. Order is `ROLE_ORDER = ['leader','admin','driver','reception']`.
   - **CARS**: id, plate, model, kind, seats. No `busy` flag; availability will be derived in Sprint 2.
     - `gl8a` 京A·D8821, 别克 GL8 / Buick GL8, 商务 / MPV, 6 seats
     - `a6` 京A·E1902, 奥迪 A6L / Audi A6L, 轿车 / Sedan, 4 seats
     - `gl8b` 京A·F3308, 别克 GL8 / Buick GL8, 商务 / MPV, 6 seats
   - **DRIVERS**: `['p-zhao']`.
   - Lookup helpers: `roomById`, `personById`, `carById`. Each returns `null` when the id is unknown.
4. **`miniprogram/data/seed.js`** exports `seed()`, which returns a **fresh deep copy** every call: `{ meetings, vehicles }`.
   - **Meetings** are m1–m5, as listed in DESIGN.md 原型数据. Copy the agendas and attendees from `prototype/app.js` `seed()`, mapped to ids.
     - Fields: `id`, `title`, `date`, `start`, `end`, `roomId`, `attendeeIds`, `organizerId`, `agenda`, `cancelled: false`, `createdAt`.
     - **No `status` field**: status is derived later in B4.
     - The seed `title` and `agenda` are `{ 'zh-CN', en }` objects (review §5.2 rule 5). Write natural English.
   - **Vehicles** are v1–v4 from the prototype.
     - Fields: `id`, `reason`, `destination`, `note` and `rejectReason` (seed text as `{ 'zh-CN', en }`; empty is `''`); `date`, `time`, `passengers`, `applicantId`, `status`, `carId`, `driverId`, `createdAt`, `dispatchedAt`, `dispatchedBy`, `completedAt`.
     - Unset ids and timestamps are `null`.
     - Make the timestamps plausible and consistent with each status.
5. **Tests**: `tests/dates.test.js`, `tests/clock.test.js`, `tests/data.test.js`.
   - **Dates:** month and year rollovers; leap day 2028-02-29; invalid dates and times.
     - `weekDays('2026-10-24', 1)` starts at 2026-10-19.
     - `weekDays('2026-10-24', 0)` starts at 2026-10-18.
   - **Clock:** demo mode returns 2026-10-24 09:20 local; `setNow` overrides it; real mode returns roughly the current time.
   - **Data integrity:**
     - every id referenced by the seed exists in the reference data
     - every bilingual object has non-empty `zh-CN` and `en`
     - `seed()` returns independent copies (mutating one doesn't affect the next)
     - no meeting has a `status` field
     - vehicle statuses are within `pending|assigned|done|rejected`, with fields consistent with status (assigned/done have `carId` and `driverId`; rejected has `rejectReason`)
6. **Cleanup from the B2 review:**

   - Remove `demo.fallbackProbe` if it exists only for a test. Keep the test working another way, e.g. with a key you delete in the test.
